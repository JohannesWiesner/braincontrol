# braincontrol

**Network Control Theory for Neuroimaging Data**

`braincontrol` provides tools for computing control energy for transitions
between brain states using [nctpy](https://github.com/LindenParkesLab/nctpy).
Its main estimator, `Transitioner`, supports NumPy, pandas, and Niimg-like
inputs.
